Orders

Estimate an order

POST /{org}/sites/{site}/orders/preview

Base URL https://api.adobecommerce.live

Staging https://api-stage.adobecommerce.live

Computes tax, shipping, and discounts for the cart against the selected shipping method and returns a signed estimateToken. reCAPTCHA-gated for unauthenticated callers.

Response

200 The estimate and signed token. Line allocations are server-calculated; bundle component allocations sum to and replace the parent allocation for component-line consumers, so never subtract both levels. price.final remains the validated catalog price.

HeaderDescription
Content-Typeapplication/json
FieldTypeRequiredDescription
subtotalstringyesMerchandise subtotal before tax and shipping.
taxAmountstringyesEstimated tax amount on the discount-reduced merchandise total.
shippingMethodobjectyesSelected shipping method and rate.
discountsobject[]yesOrder-level discounts, including shipping-only discounts.
totalstringyesEstimated order total.
lineItemsStoredOrderItem[]yesServer-resolved lines. Bundle parent and component allocations are non-additive alternate views; use only the parent or the component level when deriving effective prices.
estimateTokenstringyesSigned estimate token for order creation.

400 The preview body failed validation, shippingMethod.id is missing, or the selected method is unavailable.
