Payments

Cancel an approved-but-unconfirmed order

POST /{org}/sites/{site}/orders/{orderId}/payments/cancel

Base URL https://api.adobecommerce.live

Staging https://api-stage.adobecommerce.live

Requires the order to be in payment_requires_confirmation. Idempotent — cancelling an already-cancelled order replays. No authentication required.

Path parameters

NameTypeRequiredDescription
orgstringyesOrganization identifier.
sitestringyesSite identifier.
orderIdstringyesOrder identifier (full or friendly id).

Request headers

NameTypeRequiredDescription
AuthorizationstringnoBearer token. Bearer <jwt>. Optional — guest checkout is supported.

Response

200 The order was cancelled (or was already cancelled).
