Orders

List orders

GET /{org}/sites/{site}/orders

Base URL https://api.adobecommerce.live

Staging https://api-stage.adobecommerce.live

Returns orders for the org/site, optionally filtered by updatedAt time range and state. Requires orders:list, which admins hold and which can be granted to service tokens; the user role does not have it. The response is not paginated: all matching orders are returned at once, so keep the time range short. The API scans the whole UTC creation days from the day of since (or 30 days ago) through the day of until (or today), keeps the latest snapshot of each order, then filters on updatedAt for the bounds that were given. An order created before the first scanned day is not returned, even if it was updated inside the range.

Required permissions: orders:list
