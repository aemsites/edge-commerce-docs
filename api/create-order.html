Orders

Create an order

POST /{org}/sites/{site}/orders

Base URL https://api.adobecommerce.live

Staging https://api-stage.adobecommerce.live

Validates the order, verifies item prices/countries (or a signed estimateToken locking in tax/shipping/discounts), creates the customer if needed, and persists the order. The optional customerTimezone field stores the shopper browser timezone for customer-facing uses, such as formatting order confirmation email timestamps. reCAPTCHA-gated for unauthenticated callers.

Required permissions: orders:write

Response

200 The created order, wrapped as { order }. Item allocations are server-calculated from the verified estimate token. Bundle component allocations sum to and replace the parent allocation for component-line consumers; never subtract both levels.

400 The order was rejected, for example: it is invalid (ADOBE_COMMERCE_VALIDATION_FAILED, with per-field errors: schema validation failed, or the estimateToken is invalid or expired); it references a product path or SKU that does not exist (ADOBE_COMMERCE_REFERENCED_NOT_FOUND); or it is no longer consistent with server data (ADOBE_COMMERCE_CONSISTENCY_MISMATCH, with details). On details.field estimateToken or bundleItems (a bundle's components, their prices, or their tax classification changed since preview), re-run POST /orders/preview and retry with the new estimateToken.
